# Semana-1-PROCESA-CARNE-CON-CALIDAD-E-INOCUIDAD
Módulo III · Semana 1Recepción de carne Laboratorio virtual con simuladores interactivos para aprender a recibir la carne y decidir si se acepta o se rechaza. Incluye cadena de frío, efecto del estrés en el pH (carne PSE y DFD), inspección sanitaria, buenas prácticas en el andén, uso del termómetro de punzón y el registro en bitácora.
